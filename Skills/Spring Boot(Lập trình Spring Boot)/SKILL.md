## 🏗️ Trụ cột Kỹ thuật (Engineering Pillars)

Làm chủ Spring Boot thông qua 4 chương chuyên sâu (Mastery Chapters):

### 1. [Spring Core & Performance Internals](file:///e:/Google%20Antigravity/Skills/Spring%20Boot%28L%E1%BA%ADp%20tr%C3%ACnh%20Spring%20Boot%29/references/core_internals.md)
*Trái tim của hệ thống.*
- **IoC & DI**: Làm chủ Container và Dependency Injection hiện đại.
- **Virtual Threads (Loom)**: Cấu hình app chịu tải hàng triệu request concurrent.
- **AOP & Lifecycle**: Tách biệt cross-cutting concerns và quản lý Bean.

### 2. [Persistence & Web API Mastery](file:///e:/Google%20Antigravity/Skills/Spring%20Boot%28L%E1%BA%ADp%20tr%C3%ACnh%20Spring%20Boot%29/references/persistence_web_api.md)
*Xương sống của dữ liệu và giao tiếp.*
- **Spring Data JPA**: Giải quyết triệt để N+1 query, Locking và Projections.
- **RESTful Design**: Xây dựng API chuẩn RFC với ProblemDetails và Bean Validation.
- **Transaction Strategy**: Quản lý tính toàn vẹn dữ liệu hiệu năng cao.

### 3. [Security & Identity Flows](file:///e:/Google%20Antigravity/Skills/Spring%20Boot%28L%E1%BA%ADp%20tr%C3%ACnh%20Spring%20Boot%29/references/security_identity_flows.md)
*Lớp lá chắn chuyên nghiệp.*
- **Spring Security 6+**: Cấu hình Lambda-style, Stateless architecture.
- **JWT & OAuth2**: Triển khai Identity Provider và Resource Server.
- **Argon2 Hashing**: Bảo mật mật khẩu cấp độ Enterprise.

### 4. [Cloud Native & Distributed Scaling](file:///e:/Google%20Antigravity/Skills/Spring%20Boot%28L%E1%BA%ADp%20tr%C3%ACnh%20Spring%20Boot%29/references/cloud_native_scaling.md)
*Sẵn sàng cho quy mô toàn cầu.*
- **Spring Native**: Biên dịch GraalVM cho Startup 0.1s.
- **Microservices & Cloud**: Gateway, Config Server, Service Discovery.
- **Event-Driven**: Tích hợp Apache Kafka và Messaging patterns.
