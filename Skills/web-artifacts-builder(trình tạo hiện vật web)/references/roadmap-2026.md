# 🗺️ Lộ trình Interactive Masterpieces (2026 Edition)

Hành trình từ việc tạo một trang web đơn giản thành một bậc thầy chế tác "Hiện vật tương tác" (Artifacts).

## 🏁 Giai đoạn 1: Static Craftsman (Thợ thủ công Tĩnh)
*Mục tiêu: Làm chủ HTML/CSS và Tailwind cơ bản.*
- [ ] Học cách tạo bố cục Responsive với Tailwind CSS.
- [ ] Hiểu về Typography và hệ thống màu sắc HSL.
- [ ] Tạo được các trang Landing Page tĩnh nhưng đẹp mắt.

## 🏃 Giai đoạn 2: Reactive Apprentice (Học việc Phản xạ)
*Mục tiêu: Sử dụng React để tạo sự tương tác sinh động.*
- [ ] Sử dụng thành thạo React Hooks (`useState`, `useEffect`).
- [ ] Biết cách chia tách Component để tái sử dụng.
- [ ] Thực hành tích hợp các thành phần cơ bản của Shadcn/ui (Button, Card).
- [ ] Tạo được các Dashboard đơn giản có khả năng thay đổi trạng thái UI.

## 🏗️ Giai đoạn 3: Component Architect (Kiến trúc sư Thành phần)
*Mục tiêu: Xây dựng các hệ thống UI phức tạp trong một file duy nhất.*
- [ ] Làm chủ quản lý trạng thái với **Zustand**.
- [ ] Biết cách giả lập Routing để chuyển trang trong Artifact.
- [ ] Tích hợp sâu Shadcn/ui cho toàn bộ ứng dụng.
- [ ] Thực hành kỹ thuật xử lý Form và Validation phức tạp.

## ⚙️ Giai đoạn 4: Artifact Engineer (Kỹ sư Hiện vật)
*Mục tiêu: Tối ưu hóa quy trình Build và Hiệu năng.*
- [ ] Hiểu rõ quy trình của `init-artifact.sh` và `bundle-artifact.sh`.
- [ ] Biết cách cấu hình Bundler để inline assets và giảm kích thước file.
- [ ] Làm chủ **Framer Motion** để tạo Micro-animations mượt mà.
- [ ] Thực hành kỹ thuật Export/Import dữ liệu JSON để duy trì trạng thái người dùng.

## 👑 Giai đoạn 5: Interactive Masterpiece (Bậc thầy Kiệt tác)
*Mục tiêu: Sáng tạo những trải nghiệm tương tác không giới hạn.*
- [ ] Xây dựng được các ứng dụng phức tạp (Photo Editor, Kanban Board, CRM mini) trong duy nhất một file HTML.
- [ ] Đạt chuẩn "Aesthetic Excellence": Mọi pixel đều có chủ đích, mọi chuyển động đều tinh tế.
- [ ] Biết cách bảo mật và phân phối Artifact đến hàng ngàn người dùng qua Claude hoặc Self-hosting.
- [ ] Trở thành chuyên gia trong việc kết hợp AI để sinh mã Artifact nhanh gấp 10 lần.

> [!IMPORTANT]
> "Một Artifact vĩ đại không chỉ giải quyết được vấn đề, nó còn đem lại niềm vui thẩm mỹ cho người trải nghiệm."
