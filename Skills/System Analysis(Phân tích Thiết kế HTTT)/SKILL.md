## 🏗️ Trụ cột Phân tích (Engineering Pillars)

Làm chủ quy trình blueprinting thông qua 4 chương chuyên sâu (Mastery Chapters):

### 1. [Requirement & Process Engineering](file:///e:/Google%20Antigravity/Skills/System%20Analysis%28Ph%C3%A2n%20t%C3%ADch%20Thi%E1%BA%BFt%20k%E1%BA%BF%20HTTT%29/references/requirement_process_engineering.md)
*Gốc rễ của vấn đề.*
- **Requirements Engineering**: SMART requirements, SRS standards, và kỹ thuật 5 Whys.
- **Process Modeling**: BPMN 2.0, Flowcharts và tư duy tối ưu hóa dòng chảy (As-Is to To-Be).

### 2. [Structural & Relational Design](file:///e:/Google%20Antigravity/Skills/System%20Analysis%28Ph%C3%A2n%20t%C3%ADch%20Thi%E1%BA%BFt%20k%E1%BA%BF%20HTTT%29/references/structural_data_design.md)
*Thiết kế "bộ nhớ" hệ thống.*
- **Data Architecture**: DFD (L0-L2) và thực thể thực tế (Entities).
- **Data Integrity**: ERD chuẩn Crow's Foot, Normalization (1NF-3NF) và SQL Constraints.

### 3. [Behavioral & Interaction Modeling](file:///e:/Google%20Antigravity/Skills/System%20Analysis%28Ph%C3%A2n%20t%C3%ADch%20Thi%E1%BA%BFt%20k%E1%BA%BF%20HTTT%29/references/behavioral_interaction_modeling.md)
*Thiết kế sự tương tác.*
- **Use Case Modeling**: Phân tích Actor, Goal, và Boundary hệ thống.
- **Interaction Design**: Sequence Diagrams (Asynchronous focus) và State Machines.

### 4. [Architecture & ADRs](file:///e:/Google%20Antigravity/Skills/System%20Analysis%28Ph%C3%A2n%20t%C3%ADch%20Thi%E1%BA%BFt%20k%E1%BA%BF%20HTTT%29/references/architecture_implementation_adr.md)
*Các quyết định chiến lược.*
- **C4 Model**: Mô hình hóa kiến trúc từ ngữ cảnh đến code.
- **Decision Management**: Architecture Decision Records (ADR) và Evolutionary Design.

## 📊 Ma trận Năng lực (Competency Matrix)

| Cấp độ | Đặc điểm nhận dạng | Checklist |
|-------|----------|-----------|
| **L1: Beginner** | Hiểu User Story | Flowchart, I/O mapping cơ bản |
| **L2: Intermediate**| Vẽ được sơ đồ chuẩn | SRS, ERD (3NF), Use Case |
| **L3: Advanced** | Phân tích Behvior | Sequence Diagram, State Machine |
| **L4: Expert** | Kiến trúc hệ thống | C4 Model, Microservices, ADRs |
| **L5: Legend** | Evolutionary Design | AI Agent Orchestration, Resilience Design |
