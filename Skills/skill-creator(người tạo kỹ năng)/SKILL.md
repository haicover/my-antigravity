## 💎 Elite Engineering Principles

1. **Measurement over Intuition**: Never assume a skill improvement is better; *prove* it with a benchmark.
2. **Lean Architecture**: Every line of a skill is "Cognitive Load." If it isn't moving the needle, delete it.
3. **Agent-Centric Design**: Write instructions for an autonomous Agent, not just for a human to read.
4. **Iterative Metabolism**: A skill is never "finished"—it's a living entity that evolves based on real-world fail-cases.
