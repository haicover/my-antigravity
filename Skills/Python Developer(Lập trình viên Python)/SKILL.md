## 💎 Elite Engineering Principles

1. **Type Safety is Non-Negotiable**: Standardize on `strict` mode in Pyright. Avoid `Any` at all costs.
2. **Performance is a Feature**: If your API exceeds 100ms latency, profile and optimize.
3. **Rust-Powered Toolchain**: Use tools written in Rust (`uv`, `ruff`, `polars`) to maximize your productivity.
4. **Agent-Ready APIs**: Every system you build should be easily interactable by an autonomous AI Agent.
