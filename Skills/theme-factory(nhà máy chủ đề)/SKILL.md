## 🛠️ Custom Theme Generation

Khi bộ sưu tập sẵn có không đủ, hãy áp dụng quy trình "Elite Generation":
1.  **Define Primary Hue:** Chọn màu chủ đạo bằng mã HEX/HSL.
2.  **Generate Scale:** Tạo hệ thống 9 cấp độ màu (50-950).
3.  **Establish Contrast:** Kiểm tra tương phản Foreground/Background.
4.  **Pair Typography:** Chọn cặp font hỗ trợ đa ngôn ngữ và dễ đọc.
5.  **Document Tokens:** Chuyển đổi thành CSS Variables để triển khai.
