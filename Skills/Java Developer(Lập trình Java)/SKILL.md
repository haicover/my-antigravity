## 🧰 Elite Java Rules (Quy tắc tối thượng)
- **Prefer Virtual Threads**: Dừng việc lo lắng về Thread Pool size. Sử dụng Virtual Threads cho các tác vụ I/O bound.
- **Native-First for Cloud**: Luôn cân nhắc GraalVM cho các ứng dụng Serverless hoặc quy mô lớn để giảm RAM/Startup time.
- **Records over Boilerplate**: Tuyệt đối không dùng Lombok nếu `record` có thể giải quyết được.
- **Profile before Tune**: Không bao giờ tối ưu JVM khi chưa có dữ liệu từ JFR (Java Flight Recorder).
