## 🎯 Tầm nhìn Elite 2026: Zero-Regret Deployment
Trong kỷ nguyên AI-Native, Code Review không còn là việc "soi lỗi cú pháp" (Syntax check). Đó là một quy trình kỹ thuật bậc cao nhằm đảm bảo tính toàn vẹn của hệ thống. Mục tiêu của Elite Reviewer là đạt được **Zero-Regret Deployment** — trạng thái mà mọi dòng code được merge đều đã qua kiểm định đa tầng, đảm bảo hiệu năng tối đa và bảo mật tuyệt đối.

## 👨‍🏫 Elite Mentor (Cố Vấn Elite)

> [!TIP]
> **Vietnam perspective (🇻🇳):** Ở Việt Nam, văn hóa PR thường bị chia làm hai thái cực: hoặc là "Approve dạo" (LGTM), hoặc là cãi vã cá nhân. Kỹ sư Elite phải phá vỡ điều này. Hãy dùng dữ liệu để nói chuyện. Nếu chê code chậm, hãy đưa ra số liệu benchmark. Nếu chê code bẩn, hãy đưa ra bản Refactor mẫu. **Review code, không review con người.**
> 
> **Global perspective (🇺🇸):** Globally, we are shifting towards **Autonomous Review Pipelines**. A human reviewer is now an **Orchestrator**. Your job is to supervise the AI Agents, verify architectural alignment, and ensure "Intent-to-Code" fidelity. If a machine can find it, a human shouldn't be looking at it.

## 🧰 Elite Reviewer Persona (AI Configurations)

### 🏗️ 1. The Strict Architect (Tiêu chuẩn cấu trúc)
- **Focus**: "Code này có dễ bảo trì không? Có vi phạm SOLID không?"
- **Prompt snippet**: "Review this code as a Lead Architect. Identify any violations of Clean Architecture and suggest patterns to optimize modularity."

### 🛡️ 2. The Security Sentinel (Tiêu chuẩn bảo mật)
- **Focus**: "Code này có lỗ hổng không? Dữ liệu người dùng có an toàn không?"
- **Prompt snippet**: "Act as a Senior Security Engineer. Perform a deep-dive security audit. Look for injection risks, improper authorization, and secret leaks."
