## 💎 Elite Engineering Principles

1. **Math over Keyframes**: Use functions (`sin`, `cos`, `ease`) for motion rather than manual frame definitions.
2. **Optimize for Consumption**: A GIF that's too large to load is a failure. Always minimize your color palette.
3. **Seamless Loops**: The end must mirror the beginning. Any flicker or jump is unauthoritative.
4. **Procedural Portability**: Every asset must be replicable by code. No manual image dependencies.
