# Mobile App Developer (Nhà phát triển Mobile)

> **"One Codebase to Rule, Native Soul to Perform."**

Mobile App Developer (Elite 2026) is the unified mastery of building high-performance, intelligent, and immersive mobile experiences across all platforms. This skill consolidates Cross-Platform speed with Native precision, ensuring a zero-compromise user experience.

## Command Center
- **Core Mission**: Build diverse, high-performance mobile applications (Cross-platform & Native).
- **Core Tools**: React Native, Flutter, SwiftUI, Jetpack Compose.
- **Project Catalog**: [projects/](projects/)
- **Standard**: Elite 2026 (Modern MVVM, Clean Architecture, Edge AI).
