# 🐾 OpenClaw (Triển khai AI Agent tự chủ) — Elite Mastery Guide 2026

Chào mừng bạn đến với **OpenClaw** — hệ điều hành AI cá nhân mã nguồn mở. Không như các cloud-based agents, OpenClaw chạy trên **hạ tầng của bạn**, kết nối LLMs với các ứng dụng thực tế qua Telegram, WhatsApp, Slack, Discord, iMessage, và Signal.

> **Triết lý cốt lõi:** OpenClaw = Gateway (Router) + Agents (Brain) + Channels (Communication) + Skills (Capabilities) + Memory (Context) + Proactive Core (Heartbeats & Cron).

> **Lịch sử:** Clawdbot (Nov 2025) → Moltbot (Jan 2026) → **OpenClaw** (chính thức).

## ⚡ Quick Start (Hành động ngay)

1. **Cài đặt Docker**: Đảm bảo Docker đã cài trên máy/VPS
2. **Chạy onboard**: `openclaw onboard` — wizard dẫn bạn qua từng bước
3. **Kết nối model**: Chọn provider (Anthropic, OpenAI, Gemini, hoặc Ollama local)
4. **Thêm channel đầu tiên**: `openclaw channels add --telegram` (hoặc WhatsApp, Slack...)
5. **Chat thử**: Gửi tin nhắn đầu tiên qua channel đã kết nối
6. **Security audit**: `openclaw security audit` — kiểm tra bảo mật ngay!

---

> [!TIP]
> **Elite Rule 01:** Luôn deploy OpenClaw trên VPS/VM cô lập, KHÔNG BAO GIỜ trên máy cá nhân chính. Bind gateway về `localhost`, không phải `0.0.0.0`.

> [!IMPORTANT]
> **Elite Rule 02:** Chạy `openclaw security audit --deep` sau MỌI thay đổi config. Audit mọi skill từ ClawHub trước khi cài đặt.

> [!WARNING]
> **Bảo mật quan trọng:** OpenClaw có quyền truy cập filesystem và chạy shell commands. Nếu không bảo mật đúng cách, nó có thể bị khai thác để thực thi mã độc trên hạ tầng của bạn.
