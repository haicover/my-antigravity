# Roadmap 2026: The AI-Driven Cloud

The cloud landscape in 2026 is moving away from manual HCL/YAML writing and towards intent-based, AI-orchestrated infrastructure.

## Phase 1: Mastery of Code (Current)
- [x] Standardize Terraform / OpenTofu deployment patterns.
- [x] Adopt Pulumi for writing infrastructure in TypeScript/Python.

## Phase 2: Autonomous Scaling (Q2 2026)
- [ ] Implement KEDA (Kubernetes Event-driven Autoscaling) for precise pod scaling.
- [ ] Adopt FinOps tooling: Automated infrastructure scale-down during off-hours.

## Phase 3: AI-Generated Infrastructure (Q4 2026)
- [ ] Shift to Intent-Based Deployment: "I need a scalable backend with Redis and PostgreSQL in us-east-1." The AI agent writes and applies the Pulumi code.
- [ ] Self-healing networks that automatically rewrite traffic rules during an active DDoS attack.

## Career Vision
- Move from "Infrastructure Engineer" to "Platform Architect" — enabling business speed rather than managing servers.
