# Cloud Native & IaC (Kiến trúc Đám mây & IaC)

> **"If it's not automated, it doesn't exist."**

Cloud Native & Infrastructure as Code (IaC) is the ultimate capability for delivering high-availability, scalable systems. In 2026, manual server configuration is dead. This skill empowers you to define complete AWS, GCP, or Azure architectures in code and deploy them in minutes, guaranteeing 100% environment parity from dev to production.

## Command Center
- **Core Mission**: Architect and provision self-healing, global-scale infrastructure with zero manual clicks.
- **Master Stack**: Terraform, Pulumi, Kubernetes (K8s), Serverless Framework.
- **Standard**: Elite 2026 (Immutable Infrastructure, Zero-Trust Networking).

## The Deployment Creed
- **Immutable**: Never SSH into a server to fix it. Destroy it and let Auto-Scaling replace it.
- **Declarative**: Declare the expected state, not the steps to get there.
- **Cost-Aware**: Infrastructure code must inherently include budget limits and auto-sleep rules.
