# 🎨 Frontend Developer (Kiến trúc Frontend) — Elite Mastery 2026

Chào mừng đến với **Elite Frontend Engineering** - Lộ trình chuyển dịch từ "Coder Giao diện" thành "Kiến trúc sư Trải nghiệm". Năm 2026, Frontend không chỉ là HTML/CSS mà là hệ sinh thái phức tạp của **Server Components**, **Edge Computing**, và đặc biệt là **AI-Native Development Workflow**.

> [!IMPORTANT]
> **Triết lý 2026:** UI là sản phẩm cuối cùng mà người dùng chạm vào. Engineering Rigor ở Frontend quyết định sự thành bại của Business. Hãy code với tư duy **Pixel-Perfect** và **Zero-Latency**.

## 📌 Phase Spotlight

### Phase 4 — Component Architecture
Năm 2026, **React Server Components (RSC)** là mặc định. Kỹ sư Elite phải biết phân tách rạch ròi giữa Server và Client, tận dụng **Streaming SSR** để đạt FCP (First Contentful Paint) dưới 500ms.

### Phase 8 — AI-Native Development
Sử dụng các công cụ như **Claude Code**, **Cursor**, và **Antigravity** không chỉ để generate code, mà để **Refactor System**, viết **Automated Unit Tests**, và **Debug Race Conditions** một cách thần tốc.

## 🧰 Quick Reference Cheat Sheet

- **Performance Rule**: Tránh `useEffect` cho data fetching; dùng **TanStack Query**.
- **State Selection**: Local State → URL State → Server State → Global Store (Chỉ khi thực sự cần).
- **TS Strict**: Luôn bật `noImplicitAny` và `strictNullChecks`.
- **Responsive**: Ưu tiên **Mobile First** và tận dụng CSS Container Queries.
