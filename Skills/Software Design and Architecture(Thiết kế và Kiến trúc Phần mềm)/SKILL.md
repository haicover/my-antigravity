## 🎯 Tầm nhìn 2026 (Vision)
Kiến trúc phần mềm năm 2026 không còn là những bản vẽ tĩnh. Nó là một thực thể sống động, tập trung vào **Khả năng thích ứng (Adaptability)** và **Kiến trúc Tiến hóa (Evolutionary Architecture)**. Chúng ta thiết kế để hệ thống có thể thay đổi nhanh hơn tốc độ thay đổi của thị trường.

---

## 🏛️ Trụ cột Kiến trúc (Architectural Framework)

Làm chủ 4 trụ cột chính thông qua các chương chuyên sâu (Mastery Chapters):

### 1. [Modern Patterns & SOLID](file:///e:/Google%20Antigravity/Skills/Software%20Design%20and%20Architecture%28Thi%E1%BA%BFt%20k%E1%BA%BF%20v%C3%A0%20Ki%E1%BA%BFn%20tr%C3%BAc%20Ph%E1%BA%A7n%20m%E1%BB%81m%29/references/patterns_principles.md)
*Tối ưu mã nguồn ở mức vi mô.*
- **SOLID / GRASP**: Nguyên tắc gán trách nhiệm và quản lý khớp nối.
- **AI-Native Interface**: Thiết kế code để AI dễ đọc, dễ debug và dễ sinh code.
- **Composition over Inheritance**: Ưu tiên sự linh hoạt của Protocol-driven design.

### 2. [Clean & Evolutionary Architecture](file:///e:/Google%20Antigravity/Skills/Software%20Design%20and%20Architecture%28Thi%E1%BA%BFt%20k%E1%BA%BF%20v%C3%A0%20Ki%E1%BA%BFn%20tr%C3%BAc%20Ph%E1%BA%A7n%20m%E1%BB%81m%29/references/evolutionary_clean_arch.md)
*Xây dựng ranh giới hệ thống (Boundaries).*
- **Hexagonal / Onion / Clean**: Tách biệt logic kinh doanh khỏi chi tiết hạ tầng.
- **Architectural Fitness Functions**: Tự động hóa việc kiểm thử kiến trúc bằng code.
- **Decoupling Strategy**: Quản lý ranh giới vật lý và logic.

### 3. [Domain-Driven Design (DDD)](file:///e:/Google%20Antigravity/Skills/Software%20Design%20and%20Architecture%28Thi%E1%BA%BFt%20k%E1%BA%BF%20v%C3%A0%20Ki%E1%BA%BFn%20tr%C3%BAc%20Ph%E1%BA%A7n%20m%E1%BB%81m%29/references/ddd_strategic_tactical.md)
*Xử lý độ phức tạp nghiệp vụ (Business Core).*
- **Strategic Mapping**: Bounded Contexts, Ubiquitous Language, Context Maps.
- **Tactical Patterns**: Entities, Value Objects, Aggregates, Domain Events.
- **Consistency Boundaries**: Đảm bảo toàn vẹn dữ liệu trong các ranh giới nghiệp vụ.

### 4. [Distributed System Design](file:///e:/Google%20Antigravity/Skills/Software%20Design%20and%20Architecture%28Thi%E1%BA%BFt%20k%E1%BA%BF%20v%C3%A0%20Ki%E1%BA%BFn%20tr%C3%BAc%20Ph%E1%BA%A7n%20m%E1%BB%81m%29/references/distributed_system_design.md)
*Vươn tới quy mô và tính ổn định.*
- **CQRS & Event Sourcing**: Tách biệt luồng đọc/ghi và lưu vết lịch sử.
- **Saga Pattern**: Quản lý giao dịch phân tán và logic bù đắp (Compensating).
- **Observability Tracing**: Quan sát hệ thống 360 độ bằng OpenTelemetry.

## 📊 Ma trận Năng lực (Competency Matrix)

| Cấp độ | Đặc điểm nhận dạng | Chuyên môn |
| :--- | :--- | :--- |
| **L1: Code Dev** | Viết code chạy được | Clean Code, SOLID cơ bản |
| **L2: Design Pro** | Áp dụng Pattern hiệu quả | GoF Patterns, GRASP |
| **L3: Architect** | Thiết kế ranh giới tốt | Hexagonal, Clean Arch, DDD Tactical |
| **L4: Distributed** | Xử lý hệ thống phân tán | Microservices, CQRS, Saga |
| **L5: Enterprise** | Tầm nhìn chiến lược | Strategic DDD, Global Scale, AI Governance |
