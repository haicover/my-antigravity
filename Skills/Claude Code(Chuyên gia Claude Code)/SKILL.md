## 🎙️ Mentor Section (Góc Nhìn Chuyên Gia)

### 🇺🇸 English Perspective
In 2026, Claude Code is the gold standard for agentic coding. The biggest mistake beginners make is treating it like a chatbot. It's an **autonomous agent** — feed it context (CLAUDE.md), give it a clear plan, and let the agentic loop do the work. Master three things: **Context management** (use `/compact`, track token costs), **CLAUDE.md architecture** (treat it like a system prompt for your codebase), and **Hooks/Subagents** (automate guardrails and parallelize work). The developers who scale Claude into CI/CD pipelines with headless mode and agent teams will 10× their output.

### 🇻🇳 Góc Nhìn Tiếng Việt
Năm 2026, Claude Code là chuẩn vàng của lập trình agentic. Sai lầm lớn nhất của người mới là coi nó như chatbot. Đây là một **agent tự chủ** — hãy cung cấp ngữ cảnh (CLAUDE.md), đưa ra kế hoạch rõ ràng, và để agentic loop tự hoạt động. Hãy làm chủ 3 điều: **Quản lý context** (dùng `/compact`, theo dõi chi phí token), **Kiến trúc CLAUDE.md** (coi nó như system prompt cho codebase), và **Hooks/Subagents** (tự động hóa guardrails và chạy song song). Những ai mở rộng Claude vào CI/CD pipelines với headless mode và agent teams sẽ tăng năng suất gấp 10 lần.

## 🧰 Quick Reference Cheat Sheet (Elite Commands)

### Keyboard Shortcuts
| Phím tắt | Hành động |
|----------|-----------|
| `Ctrl+C` | Hủy generation hiện tại |
| `Ctrl+R` | Tìm lịch sử lệnh (reverse search) |
| `Esc` | Hủy input / dismiss |
| `Esc + Esc` | Dừng agentic loop ngay lập tức |
| `Shift+Tab` | Chuyển đổi multi-line / single-line input |

### CLI Invocations
| Lệnh | Mô tả |
|-------|-------|
| `claude` | Khởi chạy REPL session tại thư mục hiện tại |
| `claude -r` | Resume session gần nhất |
| `claude "query"` | One-shot command (chạy xong thoát) |
| `claude -p "query"` | Print mode — chỉ output, không interactive |
| `claude -c <id>` | Resume session cụ thể theo ID |
| `claude --add-dir <path>` | Thêm thư mục context cho session |

### Essential Slash Commands
```
/help  /usage  /cost  /clear  /compact  /context
/status  /plan  /rewind  /exit  /export
/init  /memory  /config  /permissions
/model  /agents  /hooks  /mcp  /doctor
```

### Special Prefixes
| Prefix | Mô tả |
|--------|-------|
| `!` | Chạy shell command trực tiếp (vd: `!npm test`) |
| `\` | Escape — gửi text nguyên bản |
| `@` | Tham chiếu file/symbol (vd: `@src/utils.ts`) |

## ⚡ Quick Start (Hành động ngay)

1. **Cài đặt Claude Code**: `npm install -g @anthropic-ai/claude-code`
2. **Tạo CLAUDE.md**: Chạy `claude` rồi dùng `/init` để tự động tạo CLAUDE.md cho project
3. **Làm quen commands**: Dùng `/help` để xem danh sách lệnh, luyện phím tắt `Ctrl+C`, `Esc`, `Shift+Tab`
4. **Thử Plan mode**: Gõ `/plan` trước khi yêu cầu thay đổi lớn — review kế hoạch trước khi thực thi
5. **Quản lý context**: Dùng `/compact` khi session dài, `/clear` khi cần reset hoàn toàn

> **Elite Rule 01:** Luôn commit git trước khi yêu cầu Claude thực hiện thay đổi lớn — dễ dàng rollback nếu kết quả không như ý.

> [!IMPORTANT]
> **Elite Rule 02:** CLAUDE.md là vũ khí bí mật. Một CLAUDE.md tốt giảm 50% số prompt cần gõ và tăng 3× độ chính xác của output.
