# Roadmap 2026: Prompt-to-App

Low-code is evolving from visual drag-and-drop to completely AI-generated boilerplate architectures. The goal is to maximize the speed of business logic delivery.

## Phase 1: Mastery of Workflows (Current)
- [x] Standardize on n8n (self-hosted) to eliminate Zapier/Make API limits and costs.
- [x] Integrate webhooks directly from internal applications into Low-Code orchestrators.

## Phase 2: Headless & Serverless Integration (Q2 2026)
- [ ] Connect BaaS (Supabase) Edge Functions seamlessly to visual frontend builders (Retool) for complex, secure internal tools.
- [ ] Build reusable "Templates" for standard client requests (e.g., E-commerce integration, booking systems, CRM sync).

## Phase 3: Autonomous App Generation (Q4 2026)
- [ ] Utilize AI code generation combined with Low-Code endpoints. (e.g., "AI, configure a Supabase schema for a SaaS, then deploy an n8n workflow to handle Stripe webhooks.")
- [ ] Shift to platforms like v0.dev or bolt.new for generating full-stack MVPs purely via prompt, modifying only the core logic.

## Goal
Reduce the timeline for a standard B2B Dashboard from 4 weeks to 48 hours.
