# Rapid Automation & Low Code (Tự động hóa & Low-Code)

> **"Code is a liability. Speed is a feature."**

To deliver "anything, on time" for clients, you cannot afford to write boilerplate code. Rapid Automation is the skill of gluing systems together visually and writing code *only* where custom logic is strictly necessary. It is the bridge between the 10x Developer and the 100x Output.

## Command Center
- **Core Mission**: Build complex workflows, internal tools, and MVPs in days, not months.
- **Weapon of Choice**: n8n, Make.com, Supabase (BaaS), Firebase, Retool.
- **Protocol**: The "Hybrid Code" model (Visual pipelines + Custom Python/JS nodes).

1. [Visual Orchestration](chapters/01_visual_pipelines.md) - Mastering n8n/Make to connect APIs without code.

## The Rapid Creed
Before touching VS Code:
1. "Does a visual integration for this API already exist?"
2. "Can I configure this database via Supabase UI instead of writing migrations?"
3. If yes, **use the tool**. Save your energy for the complex AI engine.
