# Elite Quiz Application

> [!IMPORTANT]
> An interactive assessment engine wrapped in an astonishing dark-mode UI. It features real-time feedback, timers, and comprehensive result reviews.

## 🚀 Key Features

*   **Automated Question Flow**: Seamless rendering of multiple-choice questions from JSON structures.
*   **Dynamic Scoring & Timing**: A real-time visual progress bar counts down seconds, dynamically penalizing non-answers.
*   **Instant Feedback**: Color-coded responses provide instant knowledge validation.
*   **Review Answers Engine**: A post-quiz analysis screen where users systematically review correct answers versus their choices.

## 🛠 Tech Stack

*   **Vanilla JS (ES6+)**: Sophisticated state management (`userAnswers`, `currentQuestionIndex`, `score`).
*   **CSS3 Advanced Styling**: Ambient glows, backdrop-filters, and animated SVG score rings.

## 📂 Quick Start

Execute `index.html` to begin the quiz experience immediately.
