# Elite Pomodoro Timer

> [!IMPORTANT]
> A masterclass in front-end state management and design, this Pomodoro timer elevates productivity tracking with liquid gradients and smooth transitions.

## 🚀 Key Features

*   **Dynamic Theme Shifting**: The UI intelligently transitions colors based on the current mode (Focus, Short Break, Long Break).
*   **Circular Progress Indicator**: An intricate SVG ring that seamlessly counts down.
*   **State Machine Architecture**: Clean Vanilla JS robustly handles timer intervals, pausing, and skipping.
*   **Settings Modal**: Configurable work and break intervals, persisting via local storage.

## 🛠 Tech Stack

*   **Vanilla JS**: No frameworks, utilizing ES6+ features and `requestAnimationFrame` concepts.
*   **CSS Variables**: A centralized design token system allowing immediate theme switches.

## 📂 Quick Start

Simply run `index.html` in your browser. Configure your focus sessions directly via the intuitive interface.
